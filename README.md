# 🤖 Zynith-AI

## Intelligent Dataset Analytics & Pattern Detection Platform

Zynith-AI is an R Shiny-based intelligent dataset analytics platform designed to help users understand, clean, visualize, and analyze datasets through an interactive web interface.

## 🚀 Features

- 📂 CSV Dataset Upload
- 📊 Dataset Summary
- 🔍 Missing Value Detection
- 📋 Duplicate Row Detection
- 🧹 Dataset Cleaning
- 📈 Interactive Data Visualization
- 📊 Dataset Statistics
- 🔗 Correlation Analysis
- ⚠️ Outlier Detection
- 🧠 AI Dataset Insights
- 💡 AI Recommendations
- 🤖 Zynith AI Chatbot
- ❤️ Dataset Health Score
- 📥 Download Cleaned Dataset
- 📄 Download Analysis Report

## 🧠 Pattern Detection

Zynith-AI performs automated pattern analysis on numerical features.

### Correlation Analysis
The platform identifies strong relationships between numerical features.

### Outlier Analysis
The system uses the IQR method to identify potential outliers in numerical columns.

## 🛠️ Technology Stack

- R
- R Shiny
- Plotly
- Data Analysis
- Statistical Analysis
- Interactive Data Visualization
